# 参与 CodeGrow

欢迎提交课程改进、可复现 bug 与教学体验建议。开发安装、构建和测试方法见 README。

提交前运行 `npm run build:site`、`npm test`、`npm run test:server`、`npm run test:e2e`。课程变更应保留稳定 lesson ID，并同步 starter、参考提示和测试输出。不要提交 `.env`、API 密钥、生成的编译器二进制、学习数据或构建输出。

导师策略应让学生先思考；L1–L3 不提供可直接提交的完整答案。加入高级提示时应记录提示事件，避免将辅助完成统计为独立完成。

请在 Pull Request 中说明变更、复现或验证方式。贡献 CodeGrow 自写代码即同意按 MIT 许可证发布；第三方资源必须注明原始许可和来源。
