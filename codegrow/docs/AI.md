# CodeGrow AI 私人导师

CodeGrow 默认使用真正的浏览器本地大模型，而不是规则回复或预写提示。模型通过 WebLLM 和 WebGPU 直接在学生的浏览器中推理；不需要 API 密钥，选择本地模式时，问题、代码和对话不会发送给模型服务。

本地 AI 不会自动下载。学生需要在导师面板或设置页选择模型并点击“下载并启动本地 AI”，页面才会检查 GPU、下载模型资源并加载到显存。首次下载可能从数百 MB 到数 GB，后续可以复用浏览器缓存；刷新页面后仍需重新加载到显存。

## 本地模型与运行要求

默认模型为开源的 Qwen2.5-Coder，模型许可为 Apache 2.0：

| 选择 | 用途 | 预计显存需求 |
| --- | --- | --- |
| Qwen2.5-Coder 7B `q4f16` | 推荐，回答和代码理解更完整 | 约 5.0 GB |
| Qwen2.5-Coder 1.5B `q4f16` | 轻量设备或显存不足时使用 | 约 1.6 GB |
| 对应 `q4f32` 版本 | GPU 不支持 `shader-f16` 时的兼容选择 | 约 5.8 GB / 1.8 GB |

这些数字是运行时显存估计，不是下载大小。使用最新版 Chrome 或 Edge，开启硬件加速，并通过 HTTPS 或 `localhost` 打开网页。页面会显示 WebGPU 检测、下载进度、加载错误、停止和释放显存操作。官方下载来自 Hugging Face；学生也可以主动选择第三方 HF Mirror，镜像的可用性由第三方负责。

完整启动步骤、缓存说明和 GPU 排障见[本地 AI 使用与排障](LOCAL_AI.md)。

## 对话原则与上下文

导师优先回答学生当下真正提出的问题，并结合最近对话、当前课程、编辑器代码以及与当前代码匹配的最近运行错误和输出。学生表示没听懂时，模型应换用更简单的说法或更小的步骤；需要时可以给解释、例子和 C 代码块。回复最后给一个与当前问题有关的可执行下一步。

系统不再提供“教学模式”、L1–L4 提示等级或预写的本地兜底答案。模型没有启动、请求失败或回复无效时，界面显示明确错误，不会伪造一条看似来自 AI 的回答。导师输出只作为文本和代码块展示，不会自动修改 Monaco 编辑器，也不会声称已经运行代码或保存学习数据。

本地模型的上下文窗口为 4096 tokens，并为回复预留空间。为了避免超出预算，只发送近期对话，较长的代码、错误和输出会按优先级截断；当前问题本身不会被静默截断。浏览器本地模式单次问题最多 2,000 个字符，若问题或序列化后的上下文仍超出预算，页面会要求把问题拆成几个步骤。云端代理仍使用下述较大的通用请求上限。

## 对话保存与学习记录

成功完成的用户/导师消息对保存在浏览器 SQLite 数据库中，使用全局会话键 `private-mentor`，最多保留最近 20 轮完整问答。刷新页面或在页面间导航后可以继续对话；正在生成、被取消或失败的半条回复不会保存。

与导师聊天本身不会自动扣减独立性，也不会生成提示事件。运行课程样例时，学生通过“本次练习由我独立完成”复选框自行标记本次尝试；运行开始时会锁定当时的选择并写入学习证据。旧数据库中的提示等级记录仅用于兼容历史数据和旧版统计。

## 可选 OpenAI-compatible 代理

`server/index.mjs` 是可选的 Node.js 代理，适用于学生或部署者已有 OpenAI-compatible 模型服务的情况。浏览器本地 AI 不依赖这个服务，也不要求创建任何云端账户。代理密钥只存放在服务端环境变量中，绝不能写入浏览器代码、`VITE_*` 变量或提交到仓库。

在 `codegrow` 目录复制 `server/.env.example` 为 `server/.env` 并填写自己的配置，然后运行：

```sh
node --env-file=server/.env server/index.mjs
```

服务默认监听 `127.0.0.1:8787`，健康检查为 `http://127.0.0.1:8787/health`。网页设置中可以填写基础地址或完整的 `/v1/tutor` 地址。`AI_BASE_URL` 必须使用 HTTPS；只有 `localhost`、`127.0.0.1` 或 `[::1]` 允许使用 HTTP。代理保持 TLS 校验且不跟随重定向。

| 变量 | 说明 |
| --- | --- |
| `AI_API_KEY` | 仅服务端读取；未配置时 `/v1/tutor` 返回明确的 503 |
| `AI_BASE_URL` | OpenAI-compatible API 基础路径，默认 `https://api.openai.com/v1` |
| `AI_MODEL` | 模型名称，默认 `gpt-4o-mini`，必须是供应商实际支持的模型 |
| `HOST` / `PORT` | 监听地址和端口，默认 `127.0.0.1` / `8787` |
| `CODEGROW_ALLOWED_ORIGINS` | 精确网页 Origin 列表，以英文逗号分隔，不支持通配符 |

### 请求合同

`POST /v1/tutor`，`Content-Type: application/json`：

```json
{
  "message": "循环为什么没有结束？",
  "code": "int i = 0; while (i < 3) { printf(\"%d\", i); }",
  "lessonTitle": "while 循环",
  "history": [
    { "role": "user", "content": "我试过把条件改成 i <= 3。" },
    { "role": "assistant", "content": "条件边界改变了，但还要检查 i 是否更新。" }
  ],
  "lastError": "运行超时",
  "output": "000000"
}
```

只有 `message`、`code`、`lessonTitle`、`history`、`lastError` 和 `output` 可以出现，未知字段会被拒绝。限制如下：

- `message`：必填、非空，最多 4,000 字符；
- `code`：必填，最多 20,000 字符；
- `lessonTitle`：必填，最多 200 字符；
- `history`：可选，最多 12 条 `user` / `assistant` 消息；每条最多 6,000 字符，总计最多 24,000 字符；
- `lastError`、`output`：可选，各最多 4,000 字符；
- 整个请求体最多 192 KiB，同一来源地址每分钟最多 30 次请求。

成功回复保持前端合同：

```json
{ "content": "循环体没有改变 i，所以条件一直为真……", "source": "ai" }
```

客户端等待云端代理最多 35 秒，代理等待上游模型最多 30 秒；代理接收的上游响应体最多 64 KiB。认证失败、额度限制、连接失败、超时、请求过大或模型回复格式错误都会返回结构化错误，前端展示错误而不会生成假回复。服务不会执行学生代码、自动修改编辑器或替模型声称持久化了数据。

## 云端部署边界

仓库只提供可选代理代码，不包含托管的模型服务。若要让公网网页使用云端导师，必须另行准备模型供应商与独立托管环境，并在入口配置 HTTPS、身份认证、用户配额、日志脱敏和精确 CORS。CORS 只限制浏览器来源，不能代替认证；不要把带有供应商密钥、但没有认证和限额的代理直接暴露到公网。

学生代码、历史对话、错误和输出都会被当作不可信学习资料，不能改变固定系统角色或索取服务端密钥。使用云端代理时，这些内容会离开浏览器，请勿在代码或问题中放入密钥及个人敏感信息。

## 验证范围

自动测试使用 WebLLM 引擎 mock、固定浏览器 fixture 和代理 stub，覆盖模型选择、流式回复、取消、错误状态、请求合同、对话连续性、SQLite 持久化以及“模型回复不改写编辑器”。这些测试不等于真实显卡推理验收：当前云开发环境没有证明 7B 模型已在真实用户 GPU 上完整下载并生成回复。发布前仍应在目标用户的 Chrome / Edge、不同显存档位和实际网络环境中验证 7B 与 1.5B 的首次下载、缓存复用、显存占用和长对话表现。
